# Web デザイン研修 — 株式会社ライトパス サイトを教材にする

このフォルダは、本リポジトリの実物のコーポレートサイトを教材化した **研修パッケージ** です。

## 想定する受講者
- HTML / CSS を少し触ったことがある
- 「タグ・クラス・セレクタ」は理解している
- **Tailwind CSS / React / Next.js は初めて**

研修の最終目標は、**「この本物のサイトを 自分で改造できる」状態** になることです。

---

## 全体マップ

| ファイル | 用途 | 想定時間 |
|---|---|---|
| `00_INDEX.md`（本書） | 研修の全体像・進め方 | 10分 |
| `01_LESSONS.md` | 段階的レッスン（全15回） | 自習10〜15時間 |
| `02_CODE_TOUR.md` | コードリーディングのガイド | 4〜6時間 |
| `03_EXERCISES.md` | 手を動かす演習問題（20問） | 5〜8時間 |
| `04_SOLUTIONS.md` | 演習の解答例 | 参照用 |
| `05_DEBUG_DRILLS.md` | バグ修正クイズ（7問） | 2〜3時間 |
| `06_WORKSHOP_GUIDE.md` | 講師向けワークショップ運営手順 | 半日／1日プラン |

各文書は **独立して使える** ように作っていますが、おすすめの順番は次の通りです:

```
LESSONS（読みながら手を動かす）
  ↓
CODE_TOUR（既存コードを読む）
  ↓
EXERCISES（自力で課題に挑戦）
  ↓
DEBUG_DRILLS（バグを直して総合演習）
  ↓
（必要に応じて）WORKSHOP_GUIDE で対面研修に展開
```

## 研修で身につくこと

完了後、受講者は次のことができるようになります。

- **Next.js プロジェクト**を起動し、ファイルを編集してホットリロードを見る
- **Tailwind CSS のユーティリティクラス**で UI を作る
- **CSS 変数**で色テーマを集中管理する
- **モバイルファースト**でレスポンシブな画面を作る
- **React コンポーネント**を作って再利用する
- **useState で状態管理**しながら動的な UI を作る
- **next/image** で画像を最適化配信する
- **フォーム**を作って入力検証する
- **Next.js Route Handler** で簡単な API を作る
- **基本的なセキュリティ対策**を理解する
- **Vercel にデプロイ**する

## 環境

研修中は、本リポジトリの実コードを使います。次のコマンドが動くことを最初に確認してください:

```bash
# プロジェクトのルート（Hackathon-Template-main）に移動
cd Hackathon-Template-main

# 依存パッケージのインストール（初回のみ・数分かかります）
npm install

# 開発サーバを起動
npm run dev

# → http://localhost:3000 をブラウザで開く
```

問題が起きたら `05_DEBUG_DRILLS.md` の冒頭「環境トラブル一覧」を見てください。
