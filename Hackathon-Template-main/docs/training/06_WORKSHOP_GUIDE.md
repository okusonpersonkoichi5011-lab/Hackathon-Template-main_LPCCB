## 講師の立ち振る舞いコツ

### 「手を動かす時間」を必ず確保
- 講師が説明 10分 → 参加者が手を動かす 5分 のサイクル。
- 一方的な座学 30分は厳禁。必ず途中で「ここまでで止めて、自分でやってみてください」と区切る。

### 「動かない！」が出たら全員で原因を見る
- 一人が詰まったら、**画面共有してもらって全員で見る**。
- 「コンソールにエラーありますか？」「赤い文字をそのまま読み上げてください」と聞く。
- 答えを言わず、誘導で正解にたどり着かせる（10〜15分のタイムボックスを目安）。

### "なぜそうなっているか" を毎回1文添える
- 単に「ここを書きます」ではなく「これは○○のためにこう書きます」を一言添えるだけで、応用力が爆発的に伸びます。

### 質問対応の優先度
- 全員が止まる質問（環境、設定、共通ファイル）：即対応
- 個別の細かい質問：チャットで受けて休憩中にまとめて対応
- 「やりたいことが違う」質問：休憩中に個別フォロー

## つまづきポイントFAQ

### Q. `npm install` が遅い・失敗する
- ネットワーク確認、`npm cache clean --force` 後リトライ
- 会社のプロキシ環境なら `npm config set proxy ...`

### Q. ブラウザを開いても何も出ない
- `npm run dev` のターミナルにエラーが出ていないか
- ポート 3000 が他で使われていないか（`lsof -i :3000`）

### Q. Tailwind が効かない
- 「保存していない」「ファイル名が間違っている」が最頻
- 開発サーバを再起動

### Q. import パスエラー (`Cannot find module '@/...'`)
- `tsconfig.json` の `paths` を確認
- VS Code の TS サーバを再起動：コマンドパレットで "TypeScript: Restart TS Server"
