# 株式会社ライトパス コーポレートサイト 見た目編

このドキュメントは、サイトの **デザイン・UX・各ページの構成** を説明する資料です。
コード側の解説は同じフォルダの `02_コード編.md` を参照してください。

---

## 1. サイト全体の設計方針

### 1-1. ブランドカラー
| 用途 | 色 | コード |
| --- | --- | --- |
| ブランド基調色（ボタン・下線・ドット） | 黄色 | `#ebc528` |
| 文字（黄色の上） | 黒に近い濃紺 | `#0f172a`（slate-900） |
| 本文 | 濃紺 | slate-800 / slate-900 |
| 補助テキスト | 灰色 | slate-500 / muted-foreground |
| 必須バッジ | 赤 | red-500 |
| 任意バッジ | 緑 | emerald-500 |

> 黄色は **「面」**（ボタン背景・ドット・下線・枠線など）にだけ使い、**文字には使わない** ことで可読性を確保しています。

### 1-2. フォント
- **Inter**（Google Fonts）を `next/font` で読み込み、ラテン文字をモダンに、日本語はシステムフォントに自動フォールバック。

### 1-3. レスポンシブ方針
- **モバイルファースト**。クラスにプレフィックスを付けない状態が「モバイル」基準。
- `sm:`（640px〜）以降で順次「タブレット → PC」レイアウトに切り替え。
- すべてのページが 1 列 → 2〜3 列にスムーズに拡張するレイアウトです。

## 3. ページ別の見た目

### 3-1. TOP（`/`）

**目的**：会社のキャッチコピーと特徴を見せ、採用／問い合わせへ誘導する。

```
┌──────────────────────────────────────┐
│  [ヒーロー]                            │
│   歯車テクスチャ背景                   │
│   ・キャッチコピー（右→左へスライド）  │
│   ・説明文（0.5秒ディレイで追従）       │
│   ・特徴3カード（下から順に出現）       │
├──────────────────────────────────────┤
│  [採用情報・お問い合わせ]              │
│   3つのボタン：採用情報／問い合わせ／会社案内 │
├──────────────────────────────────────┤
│  [写真バンド]                          │
│   背景に黄色基調の都市画像              │
│   employee1〜3 を右→左へ流すマーキー   │
└──────────────────────────────────────┘
```

- **アニメーション**
  - ヒーローのキャッチコピー：画面右から左へ移動＋透明度 0→100（1 秒）
  - 説明文：上記と同じ動きを 0.5 秒遅延
  - 特徴 3 カード：画面下から 0.5 秒でフェードアップ、100/200/300ms ずつスタッガー
  - 写真バンド：右→左に常時マーキー（32 秒で 1 周）、ホバーで一時停止

### 3-2. 会社案内（`/company`）

**目的**：会社概要・代表挨拶・事業内容・所在地を一望できる総合案内。

```
COMPANY バナー（焼き込み済み英字タイトル）
   ↓
集合写真
   ↓
会社概要（会社名・住所・電話・営業時間 等を表で）
   ↓
代表挨拶（横長写真＋本文・実線の枠で囲む）
   ↓
サービス案内（旧サービス案内ページから統合：画像付き3カード）
   ↓
案件実績一覧（楽天グループ株式会社 他）
   ↓
アクセスマップ（Google マップ埋め込み＋徒歩説明）
   ↓
アクセス情報（信濃屋の写真＋目印）
   ※ 写真をクリックで拡大表示（ライトボックス）
```

- **アニメーション**
  - サービス案内 3 カード・代表挨拶・アクセスマップ：画面外右から左へスライド
  - 案件実績一覧：画面下からフェードアップ（0.5 秒）

### 3-3. 採用情報（`/recruit`）

**目的**：募集職種・社内雰囲気・応募の流れ・エントリーフォームを集約。

```
Recruit バナー
   ↓
エンジニア候補募集（リード文・右からスライドイン）
   ↓
募集職種（3カード）
   システム／インフラ／ヘルプデスク。ホバーで わずかに拡大
   ↓
こんな人が集まっています！
   左：集合写真（左からスライドイン）
   右：紹介文（早め）＋ 当てはまる人リスト（遅れて）
   ↓ ↓
   ▼ 社員インタビューはこちら（黄色のボタン）
   開閉式：押下で 4 名分のインタビューカードが下から順番に出現
   各カードは枠サイズを揃え、長文は内部スクロール
   ↓
応募の流れ（5 STEP・縦タイムライン）
   黄色いドット同士を黄色い縦線でつなぐ
   ↓
エントリーフォーム
   見た目は「必須=赤バッジ」「任意=緑バッジ」のテーブル状
   各項目に行レイアウト：[バッジ][ラベル][入力欄]
```

#### エントリーフォームの特徴
- **姓・名 / せい・めい** を分けた入力
- **電話番号は1行で表示**（住所と同じ並び）
- **住所は分割**：郵便番号／都道府県／市区町村／字名・番地／建物名
  - 郵便番号を 7 桁入れると **都道府県・市区町村が自動入力**
- **ご希望の雇用形態（3 区分のラジオ選択）**
  - 正社員（新卒採用）／正社員（キャリア採用）／パート・アルバイト
- **履歴書（PDFのみ・全雇用形態で必須）**
- **職務経歴**
  - 新卒採用 → 入力欄ごと非表示
  - キャリア採用・パート → 「テキスト入力／ファイルアップロード」を切替可能
- ファイルは **PDF 専用**：拡張子・MIME・先頭バイトの3点で検証。非PDFはサーバ側が 400 Bad Request

### 3-4. お問い合わせ（`/contact`）

**目的**：会社・サービス・協業相談など、採用以外の窓口。

```
Contact バナー
   ↓
案内文（個人情報保護方針リンク付き）
   ↓
お問い合わせフォーム
   採用と同じ「必須=赤・任意=緑」のバッジ＆3カラム行
   姓・名／ふりがな／メール／御社名／電話／住所一式／件名／本文
   送信ボタンは 黄色（黄色基調に統一）
```

### 3-5. プライバシーポリシー（`/privacy`）

**目的**：個人情報の取り扱い方針を提示。

- Privacy Policy バナー
- 7 つの条項（取得 / 利用目的 / 第三者提供 / 安全管理措置 / 開示等 / 法令遵守 / 窓口）

## 4. フォームの3段階フロー

両フォーム（お問い合わせ・採用エントリー）は共通の挙動です。

```
┌─────────┐  「入力内容確認」 ┌─────────┐  「送信する」  ┌─────────┐
│  入力画面 │ ───────────────→ │ 確認画面 │ ─────────→ │  完了画面 │
│         │ ← 「修正する」 ── │         │              │         │
└─────────┘                  └─────────┘              └─────────┘
```

- **入力画面**：必須項目の自前バリデーション（HTML5 標準ポップアップは抑止）
  - 項目下に **赤字エラー文**（例：`メールアドレスの形式で入力してください。`）
  - エラー項目の入力枠は **赤い枠線** に変化
  - 修正し始めるとそのエラーは **自動で消える**
- **確認画面**：項目をまとめて表示、「送信する」「修正する」（修正は入力内容を保持して戻る）
- **完了画面**：「送信が完了しました（デモ）」表示
- 画面切り替え時は **フォーム上端へスムーズスクロール**（ページ最上部には飛ばない）

## 5. 主要アニメーション一覧

| 名前 | 用途 | 動き |
| --- | --- | --- |
| `lp-animate-slide-in-right` | TOPヒーローのコピー | 画面右(+60px) から 1 秒でスライド＋フェード |
| `lp-animate-fade-up` | 各見出し等 | 下から軽くフェードアップ（0.8 秒） |
| Reveal `fade-up-strong` | 特徴カード等 | 下から強めにフェードアップ（0.5 秒） |
| Reveal `slide-right` | 会社案内のサービス／代表挨拶／アクセス | 画面外右から左の定位置へ（0.5 秒） |
| Reveal `slide-left` | 「こんな人」の写真 | 画面外左から右の定位置へ（0.5 秒） |
| `lp-marquee` | TOP写真バンド | 右→左へ無限スクロール |
| `lp-card-hover-zoom` | 採用ページの職種カード | ホバーで `scale(1.04)` |
| `lp-hover-lift` | 多くのカード | ホバーで 3px 持ち上がる |

> ブラウザの「動きを減らす」設定（`prefers-reduced-motion: reduce`）が有効なときは、これら全てが無効化されます（アクセシビリティ対応）。

## 7. アクセシビリティ配慮

- 画像には `alt` テキスト（装飾画像は空 `alt=""`）
- ボタン・リンクには `aria-label` / `aria-current`（現在ページ）
- フォームの入力欄は `<label htmlFor>` で対応付け、エラーは `role="alert"`、`aria-invalid` / `aria-describedby` で読み上げ可能
- すべてのコントロールにキーボード操作（フォーカスリング、ESC）
- 動きを減らす設定で全アニメオフ

## 8. 表示確認用のチェックリスト

| 項目 | 確認方法 |
| --- | --- |
| ヘッダーのロゴ・社名サイズ | PC とスマホで両方確認 |
| ハンバーガーメニュー | スマホ幅にしてアイコンタップ → ドロワーが右から出る |
| TOP の歯車背景 | 高解像度モニタ・Retinaで滲みがないか |
| 写真バンドのマーキー | 右→左に流れ、3 枚同時表示、ホバーで停止 |
| 会社案内 代表挨拶 | 枠が実線になっているか |
| アクセス情報の画像 | クリックで拡大表示・閉じる動作 |
| 採用フォーム | 必須項目が赤、任意が緑、エラー赤字、PDF 以外を選ぶと拒否 |
| 採用フォームの郵便番号 | `1500043` を入れると都道府県・市区町村が入る |
