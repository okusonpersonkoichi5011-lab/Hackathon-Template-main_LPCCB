# 解説スライド `サイト解説資料.pptx` の生成手順

このフォルダの `generate-slides.js` を実行すると、本サイトの解説資料スライド（PowerPoint 形式）が生成されます。

## 必要なもの
- Node.js（推奨 v18 以上）
- インターネット接続（初回の `pptxgenjs` ダウンロードのみ）

## 実行方法

### Windows (PowerShell / コマンドプロンプト)

```powershell
cd C:\Users\koich\OneDrive\デスクトップ\Hackathon-Template-main_LPCCB\Hackathon-Template-main\docs
npm init -y                # 初回のみ
npm install pptxgenjs      # 初回のみ
node generate-slides.js
```

実行すると同じフォルダに `サイト解説資料.pptx` が生成されます。

### より手軽に（プロジェクトに既にインストール済みの場合）

プロジェクトの `node_modules` にすでに pptxgenjs があれば、`npm install` は不要です。

## 編集したい場合

`generate-slides.js` はテキストファイルなので、内容を直接書き換えて再実行すれば反映されます。
スクリプト上部の `C` オブジェクトで色を、各セクション（`// Slide N:` のコメントブロック）で個別スライドを編集できます。

## 色のテーマ

ブランドカラー（黄色 `#EBC528`）を基調にした配色になっています。スライド上では:
- ダーク（slate-900）：タイトル・セクション表紙・まとめ
- 黄色：アクセント・CTA・ハイライト
- 白／薄グレー：本文ページの基調
- 赤（必須）・緑（任意）：フォーム関連のバッジ表現

## トラブルシューティング

- `npm install pptxgenjs` で SSL エラーが出る場合は、社内プロキシ等の設定をご確認ください。
- 生成された pptx を PowerPoint で開いて「修復しますか」と聞かれた場合は、本リポジトリにフィードバックをお寄せください（生成ロジックを修正します）。
